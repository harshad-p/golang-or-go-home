# golang-or-go-home 🐹

A personal learning repository documenting my journey learning the Go programming language — from the basics to real-world projects.

## What's in here?

This repo contains small programs, exercises, and experiments written as I progress through Go concepts, including:

- Variables, types, and functions
- Control flow and loops
- Structs, interfaces, and methods
- Error handling
- Concurrency with goroutines and channels
- And more as I go...

## Prerequisites

- [Go](https://go.dev/dl) 1.20+
- [Go extension for VS Code](https://marketplace.visualstudio.com/items?itemName=golang.go)

## Running any program

```bash
go run main.go
